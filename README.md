AR Restaurant Menu (Web AR & Backend)

A full-stack Web AR Restaurant application built with React (Vite) and Node.js. It allows users to explore restaurant menu items in interactive 3D, view food in Augmented Reality (AR) using Google Model Viewer, manage a shopping cart, and submit ratings/feedback directly to a backend server.

---

## Features
* **Interactive 3D & Web AR:** View food items (Pizza, Burgers, Drinks, etc.) in 3D and place them in the real world using mobile AR.
* **Shopping Cart System:** Add items to the cart and calculate total bills seamlessly.
* **Backend Feedback & Rating:** Rate your experience and send reviews to a Node.js & Express backend.
* **QR Code Integration:** Easily scan a QR code to open and test the menu directly on mobile devices (iOS/Android).
* **Dark Yellow-Black Theme:** Custom modern dark theme styled for a sleek restaurant look.

---

## Tech Stack
* **Frontend:** React, Vite, Google Model Viewer (`@google/model-viewer`), `qrcode.react`, CSS.
* **Backend:** Node.js, Express.js.
